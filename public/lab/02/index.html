С чего начать

Пройдите чек-лист, откройте рабочую папку в VS Code и выполните в терминале:

git clone https://github.com/igorsimdyanov/calc-js.git
cd calc-js
npm install
npm run dev

Калькулятор откроется на http://localhost:5173. Нужны Git, Node.js 22.12 или новее (лучше 24 или 26 LTS) и VS Code с расширением ESLint; для части 3 — Docker Desktop.

Что сделать

  1. Склонируйте проект и запустите его как есть: npm install, npm run dev, npm test, npm run build.
  2. Подключите линтер ESLint: пакеты, eslint.config.js, команды lint и lint:fix; исправьте ошибки в src/demo.js.
  3. По желанию — соберите образ Docker и запустите калькулятор в контейнере на localhost:8080.

Критерии оценки

«3» Проект склонирован, зависимости установлены, калькулятор работает на localhost:5173, тесты проходят, сборка собирается
«4» Всё для «3», подключён ESLint, все шесть замечаний в src/demo.js исправлены, и вы можете объяснить сработавшие правила
«5» Всё для «4», проект запущен в Docker на localhost:8080, и вы можете объяснить Dockerfile и -p 8080:8080

Команды запоминать не нужно — все они есть в методичке. Результат не совпал с образцом — найдите своё сообщение в разделе «Если что-то пошло не так» в конце методички.
