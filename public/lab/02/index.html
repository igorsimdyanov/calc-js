С чего начать

Откройте в VS Code пустую папку, например C:\work, и выполните в терминале:

git clone https://github.com/igorsimdyanov/calc-js.git
cd calc-js
npm install
npm run dev

Калькулятор откроется на http://localhost:5173. Нужны Git, Node.js 22.12 или новее и VS Code, для части 3 — Docker Desktop. В компьютерном классе всё установлено, на своём компьютере поставьте программы по инструкциям ниже.

Что сделать

«3» Часть 1. Склонируйте проект, установите зависимости, запустите тесты и сборку, откройте калькулятор на localhost:5173 и посчитайте 12 + 30 = 42.
«4» Часть 2. Подключите ESLint: пакеты, команды lint и lint:fix, eslint.config.js. Исправьте шесть ошибок в src/demo.js — node src/demo.js выведет 113.
«5» Часть 3. Соберите образ Docker и запустите калькулятор в контейнере на localhost:8080.

Части выполняются по порядку: часть 1 — «3», части 1–2 — «4», все три — «5».

Как сдать работу

После каждой части сделайте скриншоты (Win+Shift+S) и вставьте их в один документ Word (Ctrl+V). Пришлите преподавателю файл ЛР2_Фамилия_Имя.docx, например ЛР2_Иванов_Иван.docx. Что должно быть на скриншотах:

  • Часть 1 — браузер с адресом localhost:5173 и ответом 42; в терминале строка Tests 9 passed (9).
  • Часть 2 — package.json с командами lint и lint:fix; VS Code с исправленным src/demo.js, а в терминале — npm run lint без ошибок и 113 от node src/demo.js.
  • Часть 3 — браузер с адресом localhost:8080 и терминал с контейнером в выводе docker ps.

Команды запоминать не нужно — копируйте их из методички. Если что-то не получается, напишите преподавателю и приложите скриншот терминала с ошибкой.
