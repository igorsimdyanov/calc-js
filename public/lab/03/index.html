С чего начать

Откройте в VS Code папку calc-js из лабораторной работы 2 и подключите к ней Jest по методичке. Если проекта нет, склонируйте его заново: 

git clone https://github.com/igorsimdyanov/calc-js.git
cd calc-js
npm install

Нужны Node.js 22.12 или новее и VS Code. В компьютерном классе всё установлено, на своём компьютере поставьте программы по инструкциям ниже. И ваши тест-кейсы сьюта «Арифметические операции» из лабораторной работы 1.

Что сделать

«3» Часть 1. Подключите Jest к проекту, напишите в tests/arithmetic.test.js первый тест по своему тест-кейсу TC-ARI и измерьте покрытие: npm run test:coverage.
«4» Часть 2. Добавьте ещё два теста по кейсам разных классов: другая операция, отрицательные или дробные числа, цепочка операций.
«5» Часть 3. Напишите больше трёх тестов и сгруппируйте их блоками describe; отчёт npm run test:jest -- --verbose покажет группы.

Части выполняются по порядку: часть 1 — «3», части 1–2 — «4», все три — «5».

Как сдать работу

После каждой части сделайте скриншоты (Win+Shift+S) и вставьте их в один документ Word (Ctrl+V). Пришлите преподавателю файл ЛР3_Фамилия_Имя.docx, например ЛР3_Иванов_Иван.docx. Что должно быть на скриншотах:

  • Часть 1 — VS Code с tests/arithmetic.test.js, а в терминале — вывод npm run test:coverage: таблица покрытия и Tests: 1 passed.
  • Часть 2 — VS Code с тремя тестами, а в терминале — npm run test:jest, все тесты пройдены.
  • Часть 3 — VS Code с блоками describe, а в терминале — вывод npm run test:jest -- --verbose с группами и тестами.

Тест упал? Сначала сверьте ожидание с тест-кейсом и требованиями — не подгоняйте его под то, что показал калькулятор. Подробности — в методичке, часть 2. Если что-то не получается, напишите преподавателю и приложите скриншот терминала с ошибкой.
