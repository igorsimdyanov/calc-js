# Калькулятор

Учебный проект: калькулятор в виде «Стандартный» (по мотивам калькулятора Windows)
на React + Vite.

## Быстрый старт

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm test           # модульные и компонентные тесты (Vitest + Testing Library)
npm run build      # production-сборка в папку dist/
npm run preview    # локальный просмотр production-сборки
```

Нужен Node.js 20 или новее — либо Docker, см. следующий раздел.

## Запуск в Docker (без Node.js)

Если Node.js не установлен, достаточно Docker:

```bash
docker compose up --build
```

Калькулятор откроется на http://localhost:8080. Остановить — `Ctrl+C`
или `docker compose down`.

То же без Compose:

```bash
docker build -t calc .
docker run --rm -p 8080:8080 calc
```

Образ собирается в два этапа: Node.js собирает проект, затем готовые файлы
из `dist/` раздаёт nginx — так же, как их отдаёт S3. После изменения исходников
пересоберите образ той же командой.

## Требования к калькулятору

### Ввод

- Цифры 0–9, десятичный разделитель — запятая; не более 15 цифр в числе.
- Ведущие нули не допускаются: при вводе `0`, `5` на экране `5`.
- Второй разделитель в одном числе игнорируется.
- Калькулятор работает с целыми и дробными, положительными и отрицательными числами.
- Числа выводятся с разбиением на разряды: `1 234 567,5`.

### Операции

| Кнопка | Действие |
|--------|----------|
| `+` `−` `×` `÷` | Сложение, вычитание, умножение, деление |
| `=` | Результат. Повторное нажатие повторяет последнюю операцию: `5 + 3 = =` → `11` |
| `%` | Процент: `200 + 5 %` → второй операнд `10`; `200 × 5 %` → второй операнд `0,05` |
| `¹⁄ₓ` | Обратное значение |
| `x²` | Квадрат |
| `²√x` | Квадратный корень |
| `+/−` | Смена знака |
| `CE` | Очистить текущий ввод |
| `C` | Полный сброс (память и журнал сохраняются) |
| `⌫` | Стереть последнюю цифру |
| `MC` `MR` `M+` `M−` `MS` | Очистить, считать, прибавить, вычесть, сохранить значение памяти |

- Операции выполняются цепочкой слева направо: `2 + 3 × 4 =` → `20`.
- Над основным экраном отображается выражение: `12 + 30 =`, `sqr(5)`, `√(9)`.
- Результат округляется до 15 значащих цифр: `0,1 + 0,2 = 0,3`.
- Очень большие и очень маленькие числа выводятся в экспоненциальной форме: `1e+16`.
- Индикатор `M` на экране показывает, что в памяти есть значение; `MC` и `MR` без значения недоступны.

### Ошибки

- Корень из отрицательного числа — сообщение «Недопустимый ввод».
- Деление на ноль — сообщение «Деление на ноль невозможно».
- Пока на экране ошибка, доступны только цифры, `CE`, `C`, `⌫` и `=`; любая из них сбрасывает ошибку.

### Журнал

- Каждое вычисление попадает в журнал (до 30 последних записей, новые сверху).
- Щелчок по записи возвращает её результат на экран.
- Кнопка с корзиной очищает журнал.
- На широком экране журнал всегда виден справа, на узком открывается кнопкой в заголовке.

### Клавиатура

| Клавиша | Кнопка | | Клавиша | Кнопка |
|---------|--------|-|---------|--------|
| `0`–`9` | цифры | | `Enter`, `=` | `=` |
| `.` или `,` | `,` | | `Backspace` | `⌫` |
| `+` `-` `*` `/` | операции | | `Delete` | `CE` |
| `%` | `%` | | `Esc` | `C` |
| `r` | `¹⁄ₓ` | | `q` | `x²` |
| `@` | `²√x` | | `F9` | `+/−` |

## Размещение в S3

Сборка использует относительные пути (`base: './'` в `vite.config.js`),
поэтому её можно положить в корень бакета, в любую «папку» внутри него
или просто открыть `dist/index.html` с диска.

### Amazon S3

```bash
BUCKET=my-calc-bucket
REGION=eu-central-1

npm run build
aws s3 mb s3://$BUCKET --region $REGION
aws s3 website s3://$BUCKET --index-document index.html --error-document index.html
aws s3api put-public-access-block --bucket $BUCKET \
  --public-access-block-configuration BlockPublicAcls=false,IgnorePublicAcls=false,BlockPublicPolicy=false,RestrictPublicBuckets=false
aws s3api put-bucket-policy --bucket $BUCKET --policy '{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Principal": "*",
    "Action": "s3:GetObject",
    "Resource": "arn:aws:s3:::'"$BUCKET"'/*"
  }]
}'
aws s3 sync dist/ s3://$BUCKET --delete
```

Сайт будет доступен по адресу вида
`http://my-calc-bucket.s3-website.eu-central-1.amazonaws.com`.

Обновление уже развёрнутого приложения — одной командой:

```bash
S3_BUCKET=my-calc-bucket npm run deploy
```

### S3-совместимые хранилища (Yandex Object Storage, VK Cloud, Selectel)

Включите в консоли хостинг статического сайта для бакета (главная страница —
`index.html`) и загрузите сборку, указав адрес хранилища:

```bash
npm run build
aws s3 sync dist/ s3://my-calc-bucket --delete --endpoint-url=https://storage.yandexcloud.net
```
